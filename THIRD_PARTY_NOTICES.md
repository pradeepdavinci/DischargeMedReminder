# Third-party components

Every component is free and open source.

| Component | Used for | Licence |
|---|---|---|
| Kotlin standard library | Language runtime | Apache-2.0 |
| AndroidX Core, Activity, ExifInterface | App framework, photo orientation | Apache-2.0 |
| Tesseract4Android 4.9.0 (adaptech-cz) | Android wrapper for Tesseract | Apache-2.0 |
| Tesseract OCR 5.5 | Text recognition engine | Apache-2.0 |
| Leptonica | Image library used by Tesseract | BSD-2-Clause-style (Leptonica licence) |
| libjpeg, libpng | Image decoding inside Tesseract4Android | IJG licence, libpng licence |
| tessdata_best `eng.traineddata` | English recognition model (downloaded at build time) | Apache-2.0 |

No Google Play services, Firebase, analytics, advertising or tracking libraries are used.
