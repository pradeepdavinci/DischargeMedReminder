# Contributing

Contributions are welcome – especially new prescription formats, other languages and
real-world sheet layouts.

1. Fork the repository and create a branch.
2. Keep changes small and describe what sheet format or problem they address.
3. **Never commit real patient data.** Use made-up or fully anonymised sample sheets only.
4. The review step must stay mandatory: no change may create reminders without the user
   confirming them.
5. Open a pull request; the GitHub Action builds an APK so reviewers can test it.
